# オーバーレイテンプレートの色設定をナビゲーションから分離する

コア・unitone 独自のどちらも、割り当てたオーバーレイテンプレートには、呼び出し元ナビゲーションのオーバーレイ色設定を引き継がない。テンプレートパーツの単独編集では呼び出し元の設定が見えず、編集画面と公開画面の差が分かりにくくなるため。

- 背景色・文字色の基準はサイト全体の設定とし、テンプレート内の明示的な指定を優先する。
- 文字サイズは `patterns/overlay-menu/*` の外側のセクションに unitone の M を指定する。保存済みテンプレートは自動変更しない。
- フォントなどの文字設定は包括的にリセットしない。設定項目が増えるたびに分離処理を保守する負担を避け、必要な設定をテンプレート側で指定する。
- テンプレート割り当て中はナビゲーション側のオーバーレイ色設定 UI を隠す。保存値は削除せず、割り当て解除後に再利用する。
- テンプレート未使用時の表示は維持する。フロント側では実際に描画されたテンプレートを判定し、テンプレートを取得できず通常のメニューに戻った場合にも従来の設定を適用する。

既存テンプレートがナビゲーション側のオーバーレイ色設定に依存していた場合は、必要な指定をテンプレート側へ移す。
