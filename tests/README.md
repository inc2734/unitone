# 回帰テスト

## ライセンス認証・リモートライブラリー

PHP の認証結果とキャッシュ期限、従来の保存形式・取得関数の戻り値、明示的な認証拒否と通信障害の区別、保存済み503の強制再取得、ライブラリー取得失敗と正常な空配列の区別、不正な項目だけの除外、強制再認証、設定保存・キャッシュ削除、更新クライアントの異常応答を確認する。WordPress の関数を代替した独立テストで、ネットワークやデータベースへ接続しない。Composer の依存パッケージをインストールした状態で実行する。

取得失敗は既存の transient に60秒間保存し、期限後の次の呼び出しで再取得する。正常な空配列は1週間保存する。旧版が既に24時間保存した503は、セットアップ画面の再認証で更新できることを確認する。自動的な再試行は予約しない。PHP のエラー表示・報告設定を変更しないことも確認する。

```sh
php tests/license-api.php
npm run test:settings:license
```

認証画面では、通信失敗と無効判定の区別、キーを編集しない再認証、復旧後のライブラリーキャッシュ削除、保存・削除の失敗後も再操作できることを確認する。

## プリセット参照

JavaScript の正規化、パレット照合、共有部品の保存形式は次のコマンドで確認する。

```sh
npm run test:js:presets
```

PHP 側は unitone を有効にした WordPress 環境で実行する。プリセットの正規化、保存済み HTML の互換処理、ナビゲーションの出力を確認し、投稿や設定は変更しない。

```sh
npm run wp -- eval-file tests/preset.php
```

両言語で `fixtures/preset-slugs.json` を共有し、WordPress の PHP が生成する識別子との一致を確認する。

## gap / padding の方向アイコン

未分割 UI の既定アイコン、方向の上書き優先順位、方向別 padding UI の維持、一時的な方向変更で保存属性や既存ラベルを変更しないことを確認する。

```sh
npm run test:js:spacing
```

## ナビゲーションのサブメニュー

オーバーレイ内のアコーディオンで、合成マウスイベントを含む `mousedown` 時のフォーカス移動をクリック後まで遅らせる処理を確認する。他のスタイルや通常表示には作用しない。

```sh
npm run test:js:navigation
```

## Swiper の自動再生と操作ボタン

「動きを減らす」が有効な場合の初期停止、設置済みボタンからの再生・一時停止、待ち時間0、ボタン未設置時、通常設定の自動再生を Swiper 本体で確認する。スライド・フェードでループ中の前へ・次へを連続操作しても切り替え中の状態が残らないことと、明示的な再生時に設定された切り替え時間に戻ることも確認する。

「再生 / 停止」の切り替え型については、複数の操作ボタンとの同期、フォーカス・ホバーによる停止、ポインター操作中のフォーカスによる操作反転の防止、切り替え中の表示維持を確認する。エディターのサイドバーとツールバーが保存属性を変更せず編集対象を共有すること、再生・停止それぞれの内容を保持すること、固定型の保存 HTML が変わらないことも確認する。

```sh
npm run test:blocks:autoplay
```

## パララックスと端末の動きを減らす設定

初期表示と閲覧中の設定変更でパララックスを停止し、要素を隠さず元の変形・画像位置を保持すること、停止時の未実行スクロール更新の取り消し、設定解除時の再開対象を確認する。

```sh
npm run test:js:animation
```

## カスタム HTML のブロック変換

外枠・未選択 HTML の維持、既存の内部ブロックの順序と識別子、部分的な変換失敗、属性・スタイルの省略ログ、画像のリンクとキャプション、対象テキストとファイル名の表示を確認する。変換対象内部のイベント属性・RichText 予約属性の除去、HTML エンティティや制御文字を含む危険な URL の拒否、画像とリンクの URL 許可範囲も確認する。

リストは `ul` / `ol` をリストブロック、`li` をリスト項目ブロックに変換し、入れ子・開始番号・逆順・番号形式・インライン装飾を確認する。件数は外側のリストを1件とし、属性の注意点はリスト全体または該当項目に対応付ける。未選択、既存ブロックを含む場合、画像などの未対応の内容を含む場合は、リスト全体を維持し、内部の段落や画像も個別変換しない。

1つの項目に入れ子リストが複数ある構造や、入れ子リストの後に本文がある構造は元の HTML を維持する。WordPress 7.1 本体を使う確認では、変換後の編集・保存・再読込でもブロックが有効で、本文・番号属性・入れ子を維持できることを確認する。

画面では「変換の詳細」が初期状態で閉じており、全文表示の折りたたみがないことを確認する。詳細を開いて見出し・段落・リスト・入れ子のリスト項目・画像を順に選択しても、ポップオーバー、詳細の開閉状態、スクロール位置が維持されることを通常の編集画面と iframe 内の編集画面で確認する。閉じるボタンと Esc キーによる終了、元のカスタム HTML ブロックの外側を選択した場合の終了も確認する。

閉じるボタン・Esc キー・ツールバーボタンの再クリック・外側のブロック選択でポップオーバーを閉じた後は、再度開いても以前の変換結果や注意ログが表示されず、変換済みブロックは維持されることを確認する。

画面外の項目をクリックすると、そのブロックが見える位置まで編集領域がスクロールし、すでに表示されている場合は位置が変わらないことを確認する。選択済みのブロックを画面外へスクロールしてから同じ項目を再クリックした場合も確認する。

画像のラベルがサムネイルとテキストの上にあり、サムネイルとテキストが縦中央に並ぶことを確認する。両方のクリックで対象ブロックが選択されること、画像を読み込めない場合もテキストから選択できることを確認する。

```sh
npm run test:js:html
```
